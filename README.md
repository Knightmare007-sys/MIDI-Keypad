# MIDI-Keypad
A small controller with keys that does not make sound itself instead it sends messages to computer or phone which produces sound . It uses EC11 Rotary encoder (turning the knob creates signals which the microncontroller reads to track rotation which is perfect for tasks like changing volume etc ), a waveshare esp32 s3 zero for capacitive touch (the brain of the board), 2 bourns slide potentiometers and some  low profile switches ( when u press them down they close the circuit at a specific matrix coordinate).
